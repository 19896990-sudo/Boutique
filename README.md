# Boutique
El portal permitirá a los clientes consultar el catálogo de prendas, iniciar sesión, armar su carrito y revisar sus pedidos, y a la administración gestionar los productos y descargar reportes de ventas. Contar con esta planificación antes de programar evita rehacer trabajo y asegura que el sitio responda a lo que el cliente realmente necesita
